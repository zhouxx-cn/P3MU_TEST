# 基线DSP模块更新说明

## 文件说明
    该文件记录了基线更新日志，后续会随发布包一起发布；
    更新时请对照之前版本的ReleaseNote.md文件，查看更新项，并进行修改功能验证；
    更新说明中，[]中指明了修改影响的版型，请着重关注自己对应版型的修改项；
    下面时对应更新影响范围的说明
     - [ALL] 影响所有版型
